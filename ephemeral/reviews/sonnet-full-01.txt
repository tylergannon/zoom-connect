**Material finding**

1. **The admin Zoom page crashes once any webhook has been logged.**
   - **Where:** `web/src/routes/admin/zoom/+page.svelte:36` and `:45`, against `internal/httpapi/share_admin.go:166` and `:171`. The `last_webhook?: string` type is at `web/src/lib/types.ts:16`.
   - **Trigger:** `POST /zoom/webhook` records an entry, including a plain `endpoint.url_validation`. Then `/api/admin/zoom` returns `last_webhook` as an object (`{at, event, topic, outcome}`), not a string.
   - **Effect:** `webhookTime()` passes that object to `relativeDate()`. It becomes `new Date(object)`, an Invalid Date, and `Intl.DateTimeFormat.format` throws a `RangeError` during render. The page errors instead of showing settings, and it stays broken until the server restarts, because the webhook log is kept in memory.
   - **Fix:** use `settings.last_webhook?.at` in the page and correct the type.
   - **Not hit today:** with an empty webhook log, `last_webhook` is null and the page renders.
