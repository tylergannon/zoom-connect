Design notes
Purpose
Everything an agent author needs on one screen, with real call IDs and the user's own key names filled in.
Behavior
Key picker only changes the example labels; secrets are never re-shown.
Every code block has a copy button (hover).
Serve the same content as
/api/v1/openapi.yaml
and a plain
/llms.txt
so agents can read it themselves.
Scope
MVP. Claim U7 — "stream or download the entire structured text data".
Audio endpoint is Post-MVP.
Implementation
shadcn-svelte: Code Block, Table, Select, Typography. Routes are Go
+server
handlers behind bearer auth; event JSON is nlspec §5.1 unchanged. Moving nlspec's
/meetings/…
routes to
/api/v1/calls/…
and adding
/api/v1/stream
are listed as nlspec amendments.
