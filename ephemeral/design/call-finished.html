Design notes

Purpose

Read, search and download a finished call; see who has access and share it further.

Behavior

  • Same URL and layout as live; header badge changes LIVE → Ended / Interrupted.
  • In-transcript search highlights and steps through matches (client-side; no server search).
  • Download menu: txt, vtt, json. Clicking a timestamp copies a deep link #t=04:12.
  • "Who can see this" lists participants and grantees; it's the same list the Share dialog edits.

Scope

MVP. Claims U5, U7, U8. Audio download and Shared media are Post-MVP (U12, nlspec C8). Talk time is cheap (sum of transcript durations) but optional.

Implementation

shadcn-svelte: Dropdown Menu, Tabs, Input, Card, Avatar, Badge, Progress (talk bars), Separator, Code Block. Server load reads events from the archive (R2) via GET /calls/{id}/events semantics; downloads hit /api/v1/calls/{id}/transcript?format=txt|vtt|json with the session cookie. Search is client-side over loaded events.
