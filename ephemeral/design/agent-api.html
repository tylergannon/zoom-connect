1. Hear about every call (live)

One long-lived SSE connection. You get an event whenever a call you can see starts, is shared with you, or ends.

curl -N -H "Authorization: Bearer $ZC_KEY" https://zc.acme.co/api/v1/stream

event: call.started
data: {"id":"01K7F3Q8ZJ…","topic":"Weekly product sync","url":"https://zc.acme.co/calls/01K7F3Q8ZJ…"}

event: call.ended
data: {"id":"01K7F3Q8ZJ…","status":"stopped"}

2. Follow one call

Replays everything so far, then streams live. Each message's id is the event seq, so reconnecting with Last-Event-ID (or ?from=) resumes with no gaps. Ends with event: end.

curl -N -H "Authorization: Bearer $ZC_KEY" \
  https://zc.acme.co/api/v1/calls/01K7F3Q8ZJ6Y4N2W9T5RXHM0VB/stream

id: 412
data: {"seq":412,"ts":1760550123456,"kind":"transcript",
       "participant":{"id":"16778240","name":"Dana Kim"},
       "data":{"text":"let's ship it monday","lang":"en","final":true}}

3. Download a whole call

GET/api/v1/callsCalls you can see, newest first. ?status=live
GET/api/v1/calls/{id}Call metadata: topic, host, participants, status
GET/api/v1/calls/{id}/eventsAll structured events, NDJSON
GET/api/v1/calls/{id}/transcript?format=txt|vtt|json
GET/api/v1/calls/{id}/audio/{p}Per-participant Ogg/Opus

Event kinds

stream.started · stream.stopped · stream.interrupted · participant.joined · participant.left · speaker.active · transcript · chat

Errors

401 missing/revoked key · 403 your key's owner can't see that call · 404 no such call

Design notes

Purpose

Everything an agent author needs on one screen, with real call IDs and the user's own key names filled in.

Behavior

  • Key picker only changes the example labels; secrets are never re-shown.
  • Every code block has a copy button (hover).
  • Serve the same content as /api/v1/openapi.yaml and a plain /llms.txt so agents can read it themselves.

Scope

MVP. Claim U7 — "stream or download the entire structured text data". Audio endpoint is Post-MVP.

Implementation

shadcn-svelte: Code Block, Table, Select, Typography. Routes are Go +server handlers behind bearer auth; event JSON is nlspec §5.1 unchanged. Moving nlspec's /meetings/… routes to /api/v1/calls/… and adding /api/v1/stream are listed as nlspec amendments.
