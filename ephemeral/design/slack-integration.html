Design notes

Purpose

Install the Slack app once and see who will (and won't) get DMs.

Behavior

  • Before install: an empty state with one “Add to Slack” button (OAuth v2).
  • Matching is by email only; mismatches are listed, not fixed here.
  • Guests and external participants never get DMs.
  • Test DM sends both message types to the admin.

Scope

Entire screen is Post-MVP. Claims U10, U11. Planned so the data model (users ↔ Slack ids, prefs) doesn't fight us later.

Implementation

shadcn-svelte: Card, Switch, Table, Badge, Button. Slack OAuth v2 install stores the bot token encrypted in settings. A notifier consumes the same call.started / call.ended / call.shared events as /api/v1/stream and calls chat.postMessage to the user's DM channel (conversations.open). users.lookupByEmail resolves Slack ids, cached.
