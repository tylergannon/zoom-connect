Design notes

Purpose

Make the one-time secret impossible to miss and revocation impossible to do by accident.

Behavior

  • Step 2 can't be dismissed by clicking outside or Esc — only the button.
  • "Copy as curl" copies a ready-to-run stream command with the key inlined.
  • Revoke shows how many live streams it will cut.

Scope

MVP. Claim U6.

Implementation

shadcn-svelte: Dialog, Field + Input, Button, Alert, Alert Dialog. skgo Form createKey returns the secret once in the form result; server stores SHA-256 hash and 8-char prefix. Secret: zc_ + base62 of 32 random bytes. Command revokeKey(id) sets revoked_at and signals sessions to drop that key's subscribers.
