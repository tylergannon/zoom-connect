Design notes

Purpose

A shared link opened by the wrong person should explain the rule and point to who can fix it, not just 403.

Behavior

  • Lists org participants (names only — no title, no transcript) so the viewer knows whom to ask. Decide whether even names leak too much; the alternative is the host only.
  • Signed-out visitors go to Sign in first, then land here or on the call.
  • API returns 403 for no access and 404 for unknown ID. If we'd rather not confirm a call exists, both become 404.

Scope

MVP. Claims U3, U8. "Ask in Slack" is Post-MVP (Slack integration).

Implementation

shadcn-svelte: Empty, Avatar, Button. Page server load throws error(403, {participants}); rendered by +error.svelte.
