Design notes
Purpose
Install the Slack app once and see who will (and won't) get DMs.
Behavior
Before install: an empty state with one “Add to Slack” button (OAuth v2).
Matching is by email only; mismatches are listed, not fixed here.
Guests and external participants never get DMs.
Test DM sends both message types to the admin.
Scope
Entire screen is Post-MVP.
Claims U10, U11. Planned so the data model (users ↔ Slack ids, prefs) doesn't fight us later.
