Design notes

Purpose

Home after sign-in. Answers "what's happening now?" and "find that call I was in".

Behavior

  • Live cards appear within seconds of a call connecting and show the latest transcript line, ticking duration, and how many agents are subscribed.
  • A live card disappears into the table when the call ends.
  • Tabs filter by access reason. Search is on title and participant name.
  • Empty state: "No calls yet. Calls appear here when Zoom Connect hears one you're in."

Scope

MVP. Claims U3, U4, U8. Search can ship as title-only first.

Implementation

shadcn-svelte: Sidebar, Card, Badge, Tabs, Input, Table (Data Table later), Avatar, Dropdown Menu, Empty. Go server load lists from the Postgres call index filtered by participant/share (T3, T9). Live cards subscribe to the user-scoped announcement stream (same events as GET /api/v1/stream, T16) via an skgo LiveQuery.
