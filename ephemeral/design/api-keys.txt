Design notes
Purpose
Self-serve keys for agents. No admin approval in MVP.
Behavior
Only the prefix (
zc_
+ first chars) is ever shown after creation.
"Streaming now" when the key holds an open SSE connection; otherwise last-used time.
Revoke asks for confirmation, then closes the key's open streams.
Revoked keys stay listed (greyed) for audit; hide them behind a toggle if the list grows.
Empty state: explains what a key is for and links to the Agent API guide.
Scope
MVP. Claims U6, U7. Per-key scoping (e.g. one call, read-only finished) is
Post-MVP
— every key acts as its owner.
Implementation
shadcn-svelte: Table, Badge, Button, Alert, Alert Dialog (revoke), Dialog (create). Store:
api_keys(id, user_id, name, description, key_hash, prefix, created_at, last_used_at, revoked_at)
. "Streaming now" comes from the session's subscriber registry, not the DB.
